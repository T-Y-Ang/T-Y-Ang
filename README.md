# Clinical AI & Computational Neuroscience

I am a clinician with an interest in neurosurgery, neuroscience, and the
application of machine learning to clinical research.

This GitHub documents my development in medical data science, from conventional
statistical and machine-learning methods to deep learning and computational
approaches to neurological and neurosurgical problems.

My current work focuses on building clinically interpretable and reproducible
models, with particular attention to prognostication, medical imaging,
physiological signals, and clinical decision-making.

## Current Projects

### 🧠 Traumatic Brain Injury Outcome Prediction
**Clinical prognostication | Machine learning | Explainable AI**

Can information available during early assessment of patients with traumatic
brain injury predict unfavourable functional outcome at 90 days?

This project compares conventional clinical prediction with machine-learning
approaches using clinical and neuroimaging variables from a multinational TBI
dataset.

**Methods:** Logistic regression · Random Forest · XGBoost · Calibration ·
Bootstrap validation · Explainability

## About This Portfolio

The projects here are intended to explore how computational methods can be
applied responsibly to clinically meaningful problems.

Where medical datasets are used, particular attention is given to data
provenance, information leakage, missing data, model calibration,
interpretability, and the limitations of clinical prediction models.
